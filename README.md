# Dashboard Connettività YTD

Dashboard statica per analizzare file Excel di connettività direttamente nel browser.

## Avvio locale

Aprire `dist/index.html`.

## Pubblicazione Netlify

Collegare questo repository a Netlify. La configurazione è già presente in
`netlify.toml`; la directory pubblicata è `dist` e non è richiesto alcun
comando di build.

## Privacy

I file Excel vengono elaborati localmente nel browser e non sono inviati a server.

## Colonne Excel

- A: Fornitore
- F: Stato
- H: Tipologia connettività
- O: Regione
- P: Data invio in attivazione
- R: Data attivazione/collaudo
